東石系統 診股

安裝到 iPhone 主畫面

  1. 建議用 Safari 開這個頁面
  2. 點下方工具列的 分享 按鈕
  3. 往下滑，選 加入主畫面，再按右上角 加入

裝好之後從主畫面開，就是全螢幕的 APP，自選股和金鑰都會保留。

FinMind 金鑰

不填也能用，但匿名查詢每小時次數較少。
到 FinMind 會員頁 免費註冊後複製 API Token 貼在這裡。

金鑰只存在這台裝置的瀏覽器裡，不會存到 GitHub 或任何伺服器（查詢時只送給 FinMind）。
