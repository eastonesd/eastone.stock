# 東石診股 eastone.stock

輸入台股代號或公司名稱，一眼看出這檔股票現在是**綠燈、黃燈還是紅燈**。

- **健康面**（財報 · 估值 · 籌碼）：ROE、EPS 成長率、本益比、負債比、三大法人連續買超
- **投資面**（量價 · 趨勢 · 波動）：供需、均線趨勢、波動性、流動性、市場情緒
- 每個細項都顯示它落在哪個級距，看得出離下一個燈號還差多少
- 近一年股價與 MA20 / MA60 / MA240 走勢圖
- 自選股清單（存在瀏覽器裡），可一鍵全部更新

👉 線上版：https://eastonesd.github.io/eastone.stock/

## 架構

純前端，沒有後端伺服器，直接放在 GitHub Pages。瀏覽器直接向 [FinMind](https://finmindtrade.com/) 抓資料，在本機算分數。

```
index.html          頁面
assets/scoring.js   評分引擎（所有級距與門檻都在這裡）
assets/finmind.js   FinMind 資料存取、股票清單快取、診斷快取
assets/app.js       畫面互動、紅綠燈、走勢圖、自選股
assets/style.css    樣式（含深色模式、手機版）
```

## FinMind 金鑰

**程式碼裡沒有任何金鑰。** 不填金鑰也能用，只是匿名查詢每小時的次數比較少。
要提高上限，到 FinMind 免費註冊，複製 API Token，貼到網頁右上角的「金鑰」。
金鑰只存在你自己的瀏覽器（localStorage），不會進到這個 repo。

每次診斷會發 5 個請求；同一檔股票 30 分鐘內重查會用快取，不重抓。

## 燈號規則

| 燈號 | 分數 |
|---|---|
| 🟢 綠燈 | ≥ 70 |
| 🟡 黃燈 | 50 – 69 |
| 🔴 紅燈 | < 50 |

細項分數（20 / 40 / 60 / 80 / 100）各自換成燈號；健康面、投資面各取 5 項平均；總分 = 健康 50% + 投資 50%。
「供需」和「市場情緒」在 MA20 下彎時分數打五折。門檻、權重都在 `assets/scoring.js` 開頭的 `DEFAULTS` 和 `BANDS`。

## 已知限制

- 股價用的是 FinMind 未還原的收盤價，遇到分割或減資（例如 0050 在 2025 年 6 月一拆四），當下前後一年的均線與波動會失真。
- ETF 沒有財報，健康面只計三大法人籌碼。
- 金融股的負債比天生偏高（銀行九成負債是常態），在這套級距下一定是紅燈，判讀時要記得。
